# Task Management App

A full-stack responsive task management web application built using the MERN stack.

## Features
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Responsive UI
- REST API Integration
- MongoDB Database Storage

## Tech Stack
Frontend:
- React.js
- CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

### Backend
cd backend

npm install

npm run dev

### Frontend
cd frontend

npm install

npm run dev

## API Endpoints

GET /api/tasks

POST /api/tasks

PUT /api/tasks/:id

DELETE /api/tasks/:id
